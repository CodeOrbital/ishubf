## About the project
### Language usage
1. Because the assignment strictly instructs to use only html, I used only HTML.
2. This means I didn't use any type of css code, not even inline css, nor Javascript.
3. But to make it as aesthetic as possible I used different HTML formatting and aesthetics related elements and attributes. Such as
 - elements :
  - `font`
  - `hr` / horizontal row
  - `br` - for spacing (since I shouldn't use padding and margin)
 - attributes :
  - `width`
  - `height`
  - `bgcolor` / background color
  - `background` - for image
  - `color`
  - `face` - in font element
  - `size`
  - **on tables**
   - `cellpadding`
   - `cellspacing`
   - `bordercolor`
   - `border`
